# 第 9 章：短期记忆 —— 对话历史与 Compact

## 9.1 问题：对话越来越长怎么办

Agent 的对话历史会不断增长。每次用户消息、AI 回复、工具调用和结果都会追加到历史中。当历史超过模型的上下文窗口时，API 调用会失败。

## 9.2 BaoClaw 的短期记忆

对话历史存储在 `QueryEngine.messages: Vec<Message>` 中。每条消息有类型：

```rust
pub enum MessageContent {
    User { message: ApiUserMessage },      // 用户消息
    Assistant { message: ApiAssistantMessage }, // AI 回复
    System { subtype, content },           // 系统消息（compact 边界）
}
```

每次 API 调用时，完整的 `messages` 列表被转换为 API 格式发送给 LLM。

## 9.3 Session Memory —— 滚动摘要

BaoClaw 为每个会话维护一个**滚动摘要**（Rolling Summary），持久化到 `~/.baoclaw/sessions/{session_id}.memory.md`。这是 Claude Code 式的设计：**会话进行中持续后台预写摘要，启动时直接加载，永不现场生成。**

### 后台更新机制

在 `run_query_loop` 的每轮结束后，检查是否需要更新摘要：

```rust
// run_query_loop 每轮结束后
if let Some(ref sm) = config.session_memory {
    let current_count = messages.len();
    if sm.should_update(current_count) {
        tokio::spawn(async move {
            update_session_memory_background(
                msgs_clone, sm_arc, api, mdl, existing,
            ).await;
        });
    }
}
```

更新策略：
- **首次触发**：消息数 ≥ 6 条时首次生成
- **刷新间隔**：之后每 10 条新消息更新一次
- **后台执行**：`tokio::spawn` 火后即忘，不阻塞当前响应流
- **增量更新**：已有摘要时，将旧摘要 + 新对话一起发给 API 更新

### Session 关闭时的兜底

如果会话太短（没触发后台更新），session 关闭时会生成 heuristic 摘要：

```rust
// session close hook
if !sm.is_available() && messages.len() >= 4 {
    // 提取用户消息标题列表
    for msg in &messages_clone {
        if let MessageContent::User { message, .. } = &msg.content {
            task_descriptions.push(first_line);
        }
    }
    sm.update(summary); // 持久化到 .memory.md
}
```

这确保了**每个会话都有摘要**，即使后台更新从未运行。

### `session_memory.rs` 的关键方法

| 方法 | 作用 |
|------|------|
| `is_available()` | 摘要是否可用（内容 > 20 字符） |
| `should_update(count)` | 是否到了更新时机 |
| `update(summary)` | 写入摘要并持久化（自动截断到 8KB） |
| `get()` | 读取当前摘要文本 |
| `set_message_count(n)` | 记录上次更新时的消息数 |

## 9.4 Compact 机制

当对话历史太长时，BaoClaw 有一套分层压缩策略：

### Level 1：Session Memory Compact（免费，无 API 调用）

使用已有的滚动摘要直接替换旧消息：

```rust
pub fn session_memory_compact(messages: &mut Vec<Message>, summary: &str) -> bool {
    let keep_recent: usize = 10;
    let boundary = Message {
        content: MessageContent::System {
            subtype: SystemSubtype::CompactBoundary,
            content: format!("[Previous conversation summarized]\n\n{}", summary),
        },
        ...
    };
    *messages = vec![boundary];
    messages.extend(recent_messages);
    true
}
```

### Level 2：API Compact（1 次 API 调用）

当没有摘要或摘要不够用时，调用 LLM 生成新摘要：

```rust
pub async fn compact(&mut self) -> Result<CompactResult, EngineError> {
    let keep_recent: usize = 10;
    let split = self.messages.len() - keep_recent;
    let old_messages = &self.messages[..split];
    
    // 截断到 60K chars，调用 API 生成摘要
    let summary = call_api_for_summary(old_messages).await?;
    
    // 替换：[摘要边界] + 最近 10 条消息
    self.messages = vec![boundary_message(summary)];
    self.messages.extend(recent_messages);
}
```

### Pre-query Compact 安全策略

提交新查询前，如果 token 超预算，触发 compact。但有安全限制：

```rust
if msg_count <= 500 {
    // 正常 API compact
    self.compact().await?;
} else {
    // 大 session（刚恢复数千条历史）→ 不能走 API compact（会卡 10 分钟）
    if sm.is_available() {
        session_memory_compact(&mut msgs, &sm.get()); // 免费
    } else {
        // 最后手段：只保留最后 100 条
        self.messages = self.messages[..100].to_vec();
    }
}
```

**关键洞察**：如果启动时恢复了数千条消息，API compact 会耗时 3-8 分钟。安全策略确保大 session 走免费路径。

### 自动 Compact（上下文窗口超出）

当 LLM 返回 `stop_reason: "model_context_window_exceeded"` 时：

```rust
if stop_reason == Some("model_context_window_exceeded") {
    tx.send(EngineEvent::AssistantChunk { 
        content: "🗜️ 上下文窗口已满，正在自动压缩..." 
    }).await;
    
    // 内联 compact：保留最近 4 条，摘要其余
    let summary = call_api_for_summary(&old_messages).await;
    messages = vec![boundary(summary)] + recent;
    
    tx.send(EngineEvent::AssistantChunk { 
        content: "✅ 压缩完成，正在重试..." 
    }).await;
    continue;
}
```

## 9.5 小结

短期记忆是 Agent 的"工作记忆"。BaoClaw 通过**三层策略**管理：
1. **滚动摘要**（Session Memory）：后台持续生成，启动时瞬时加载
2. **免费 Compact**：使用摘要替换旧消息，零 API 开销
3. **API Compact**：LLM 生成摘要，仅在必要时触发

安全策略确保大 session 恢复后不会因 compact 阻塞 10 分钟。
